# Project Title

TinyLink(node.js)
TinyLink is a simple and efficient URL Shortening Application built using Node.js, Express, and sqllite.

## 🚀 Features
- Shorten long URLs into tiny links
- Automatic redirection from short URL → original URL
- HTML frontend for submitting URLs

## 🛠 Tech Stack
- Node.js
- Express.js
- HTML/CSS
